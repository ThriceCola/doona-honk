# 迁移到 v0.1.0-beta.7

适用于从 `v0.1.0-beta.6` 升级，仅列出影响已有配置或运维预期的变更。
各版本的迁移说明与本文件并列存放。

## 1. 升级前必读

| 变更 | 处理方式 |
| --- | --- |
| `ss` 条目声明 simple-obfs 以外的 SIP002 插件（`obfs`、`obfs-local`、`simple-obfs`、`simpleobfs` 以外的名字）时，honk 现在直接拒绝，不再把插件当作无作用的元数据保留。静态配置会加载失败；订阅条目只跳过该条。 | 删掉插件，或把该条目指向 simple-obfs 服务端。 |
| 只有 `plugin_opts` 而没有 `plugin` 时会被拒绝。 | 补上插件名，或删掉选项。 |
| 原本带 `plugin=v2ray-plugin`（或其他不受支持的名字）仍能解析成明文 Shadowsocks 的分享链接，现在会被拒绝。 | 删掉该查询参数，或改用运行该插件的客户端导入。 |
| 带 simple-obfs 的 `ss` 条目现在真正做混淆，不再把密文当明文拨出去，因此派生节点 ID 会变化，按旧 ID 保存的 pin 和 Score 历史随之丢失。没有插件的条目 ID 不变。 | 若有 pin 请重新固定。之前从未连通的条目现在能连上 simple-obfs 服务端。 |
| 插件选项会被校验：`mode` 必填且只接受 `http` 或 `tls`；`tls` 配 `path` 会被拒绝；未知选项键会被拒绝；同一选项不能出现两个不同值。 | 只保留该 mode 用得上的选项；Clash 的 `plugin-opts` 与 SIP002 字符串使用同一套键。 |
| simple-obfs 只混淆 TCP。Shadowsocks 的 UDP 仍原样发往节点 host 与端口，与 dae、Mihomo 一致。 | 无需操作，除非某条规则曾假定 UDP 也被混淆。 |
